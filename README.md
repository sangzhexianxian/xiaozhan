# 小站 · 给创作者的粉丝变现站

一套可以直接部署的「粉丝变现」小站。粉丝点进来，看得见你的作品、看得见价格，点两下就能下单；你在手机上就能改价、看订单、收到通知。

不是通用建站工具，是**一条已经跑通的转化路径**：被人看见 → 相信你 → 先占个便宜 → 付钱。

> 所有钱直接进你自己的收款码，程序不碰资金，不接支付通道。

---

## 它长什么样

| 页面 | 给谁看 | 干什么 |
|---|---|---|
| `/xin/` 门厅 | 粉丝 | 三句话说清你是谁、凭什么信你、能给你什么 |
| `/xin/art` 画廊 | 粉丝 | 作品墙，标价，点开看大图，直接下单 |
| `/xin/` 写信 | 粉丝 | 留一段话，你给他回一封（付费服务） |
| `/xin/` 数字分身 | 粉丝 | 和你的分身聊几句（可选，要模型 + 音色） |
| `/xin/` 约真人 | 粉丝 | 约一个时间，视频聊（可选，要 TRTC） |
| `/xin/boss/<key>` 工作台 | 只有你 | 手机上改价、看订单、标已付款、看谁来了 |

后台还有一个「给粉丝的链接」页，一键复制门厅地址、画廊地址、短入口，直接贴到抖音/小红书/微信。

## 快速开始

```bash
# 1. 拿代码
git clone https://github.com/sangzhexianxian/xiaozhan.git xiaozhan && cd xiaozhan

# 2. 配环境
python3 -m pip install -r requirements.txt
cp .env.example .env
vi .env          # 至少填 SITE_BASE、OPS_EMAIL、SMTP_*

# 3. 起服务
python3 -m uvicorn app:APP --host 0.0.0.0 --port 8872
```

打开 `http://127.0.0.1:8872/xin/` 就是门厅。

第一次启动会自动建库，并在控制台打印**后台口令**（`desk_key` / `ops_key`）。把它记下来，工作台地址是：

```
http://127.0.0.1:8872/xin/boss/<ops_key>
```

> 忘了口令？删掉 `data/letters.db` 重启会重新生成（订单也会一起没，慎重）。

## 你会改的三样东西

| 改什么 | 在哪改 |
|---|---|
| 品牌名、副标题 | 工作台里的「设置」页，或直接改数据库 `kv` 表 |
| 作品：图片、名字、价格、上下架 | 工作台里的「画」页，或改 `art.py` 里的 `DEF` |
| 收款码 | 把图片存成 `media/pay.png`，覆盖掉占位图 |

作品图片放 `media/art/`，文件名跟 `DEF` 里对上（`p01.jpg`、`p02.jpg`…），对外地址是 `/xin/m/art/p01.jpg`。

## 配置项（.env）

| 键 | 必填 | 说明 |
|---|---|---|
| `SITE_BASE` | ✅ | 站点地址。**通知里的所有链接都按它生成**，填错则点开 404 |
| `OPS_EMAIL` | ✅ | 有人下单、有人来访，发到哪个邮箱 |
| `SMTP_*` | ✅ | 发信服务器。QQ 邮箱：`smtp.qq.com` / `465` / 授权码 |
| `LLM_*` | ⬜ | 不填则「AI 代写回信」「数字分身」自动关闭，其余功能正常 |
| `VOLC_*` `VOICE_ID` | ⬜ | 不填则分身只回文字，不出声 |
| `TRTC_*` | ⬜ | 不填则「约真人」的视频通话不可用 |

**关键设计：没配的能力会自己关掉，不会报错，不会让整站挂掉。**

## 部署到服务器

```bash
sudo cp deploy/letters.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now letters
```

nginx 反代示例见 `deploy/nginx.conf.example`（把 `/xin/` 整段转给 8872）。

上线后第一件事：把 `SITE_BASE` 改成真实域名，重启一次，否则发给粉丝的链接是内网地址。

## 上线检查单

细节见 [CHECKLIST.md](CHECKLIST.md)，最短版：

1. 门厅能打开，头像不是裂图
2. 画廊能看见作品图，点开有大图
3. 点「买」能弹出收款码，填称呼电话能提交
4. 提交后邮箱能收到通知
5. 工作台能改价、能标已付款
6. 手机上按钮够大，不用放大看
7. `SITE_BASE` 是真域名
8. 收款码是你自己的

## 设计上的几条坚持

1. **不碰资金。** 收款码是创作者本人的，钱直接进他账户。程序只负责「让人知道该付多少、付给谁、付完了怎么办」。
2. **手机优先。** 后台是给四五十岁的人用的：字大、按钮高、一屏一件事。
3. **不配也能跑。** 大模型、语音、视频通话都是可选件，缺了就优雅降级。
4. **数据自持。** 全部存在本地 SQLite，没有任何第三方统计和上报。

## 边界

- 不承诺涨粉、不承诺成交。它只把「通路」建好。
- 不做支付通道、不做资金托管、不代收代付。
- 涉及医疗、金融、法律等强监管内容，请自行确认合规。
